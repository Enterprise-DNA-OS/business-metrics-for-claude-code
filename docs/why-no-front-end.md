# Why this desk has no application front end

The reporting job needs agreed definitions, trusted numbers, comparisons and named actions. Those records live in the database. The operator asks for a scorecard, checks source coverage and records decisions through the CLI or a coding agent.

`npm run view` produces three branded read-only HTML reports. `npm run docs` produces metric review papers and action briefs. Open or print them locally. They have no controls that change records, application server or user accounts. PGlite runs locally after installation. An agent or hosted database can require network access. Report styling uses a web font with a local fallback.

Tableau provides visual authoring, interactive exploration, maps, connectors, refresh services, mobile access and governed sharing. This base does not reproduce those services or interpret workbooks. It is useful for an operator who wants to own a monthly metric review and its decisions. Teams needing interactive exploration all day need those requirements scoped before switching.

Enterprise DNA can build screens, connections and access rules around the owned records. The free base has no hosting licence or per-seat software charge. Hosting, agent subscriptions, implementation and maintenance still cost money.

Never claim Tableau cannot answer a question simply because the demo answers it. Tableau supports custom analysis too. The difference is control of definitions, evidence, reporting code and review actions.
